# Third-Party Notices / Publication Audit

This scaffold contains newly written compatibility/refactor code. Before copying existing project code, weights, meshes, URDFs, datasets or SDK files into this repository, verify their licenses and redistribution terms.

Audit at minimum:
- RoboTwin copied source/assets,
- XPolicyLab,
- exact ACT implementation,
- DP3 code if copied/adapted,
- torchvision/pretrained ResNet weights,
- SO-101 URDF/assets,
- camera SDK/OpenNI/vendor binaries,
- datasets,
- checkpoints and their training-data/pretrained-weight obligations.

RoboTwin's upstream repository currently includes an MIT license, but that alone does not establish that every third-party asset, dependency, dataset or model weight used by this project can be redistributed under the same terms.
