# RoboTwin adapter

Do not duplicate the model inside RoboTwin.

The adapter should convert RoboTwin/XPolicyLab observations into the canonical DAPIER-ACT observation contract and convert canonical 12D actions into the simulator action interface.

Before implementing this adapter, verify the exact current RoboTwin/XPolicyLab API and HDF5 image decode path in the pinned repository version.
